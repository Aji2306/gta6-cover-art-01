# GTA 6 Cover Art Maker

[![Competition Badge](https://make.fun/badge/gta6-cover-art-01.svg)](https://make.fun/c/gta6-cover-art-01)
[![Rank Badge](https://make.fun/badge/gta6-cover-art-01/Aji2306/gta6-cover-art-01/rank.svg)](https://make.fun/c/gta6-cover-art-01)
[![Reward Badge](https://make.fun/badge/gta6-cover-art-01/Aji2306/gta6-cover-art-01/reward.svg)](https://make.fun/c/gta6-cover-art-01)

A feature-rich, offline static web app that turns a person's photo and caption into stunning GTA 6 poster-style cover art with multi-panel layouts, crop/zoom controls, color grades, and one-click PNG exports in multiple sizes (1080x1080, 1080x1350, 1920x1080).

## Local Development

```bash
# Serve app/ locally on http://localhost:8080
node serve.ts

# Test dossier and export build output
MAKEFUN_OUTPUT_DIR=out node main.ts
```
